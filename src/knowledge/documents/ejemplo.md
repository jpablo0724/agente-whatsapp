# Ejemplo de documento de entrenamiento

Este es un documento de ejemplo. Reemplazalo (o agregá más archivos .md
en esta carpeta) con la información real que el agente debe usar para
responder: preguntas frecuentes, precios, horarios, políticas, guiones
de atención, etc.

Cada archivo .md de esta carpeta se carga automáticamente al iniciar el
agente — no hace falta tocar código para "entrenarlo", solo agregar o
editar estos documentos.
